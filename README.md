# Arrows Bot — نسخه ساده (v3.0-simple)

اپلیکیشن اندرویدی برای تشخیص فلش‌های آزاد در بازی‌های پازلی Arrows و لمس خودکار آن‌ها.

## قابلیت‌ها
- تشخیص تصویری فلش‌ها و جهت آن‌ها
- تشخیص مسیرهای آزاد و انتخاب فلش قابل حذف
- دکمه شناور START / STOP با قابلیت جابه‌جایی
- توقف فوری عملیات
- حداقل اندروید ۱۱ (API 30)

## ساخت APK
ساخت به‌صورت خودکار با GitHub Actions انجام می‌شود:
1. وارد زبانه **Actions** مخزن شوید.
2. اجرای workflow با نام **Build APK** را باز کنید.
3. پس از موفقیت، artifact با نام **ArrowsBot-apk** را دانلود کنید.
4. فایل ZIP را باز کرده و `app-debug.apk` را روی گوشی نصب کنید.

همچنین می‌توانید workflow را از Actions به‌صورت دستی اجرا کنید.

## راه‌اندازی روی گوشی
1. برنامه را نصب و باز کنید.
2. از داخل برنامه، سرویس **Accessibility** را فعال کنید.
3. مجوز نمایش روی برنامه‌های دیگر (Overlay) را بدهید.
4. در گوشی‌های شیائومی، در صورت نیاز Autostart را فعال و محدودیت باتری را بردارید.
5. وارد بازی شوید و دکمه شناور سبز **START** را بزنید؛ برای توقف **STOP** را لمس کنید.

## نکات
- این ابزار با دسترسی Accessibility از صفحه اسکرین‌شات می‌گیرد و gesture لمسی ارسال می‌کند.
- عملکرد تشخیص به رنگ‌ها، چیدمان و نسخه بازی وابسته است و ممکن است نیازمند تنظیم پارامترهای `Solver.kt` باشد.
- این پروژه تضمین‌کننده حل بدون خطا در همه نسخه‌های بازی نیست.
